# Actividad el laberinto de datos.
## *Aplicar estructuras complejas en la resolución de problemas.*
Pasos para abrir el archivo de python laberinto_datos.py
1. Descarga de este repositorio de github el archivo "laberinto_datos.py"
2. Abre tu editor de código
3. Dentro del editor haz clic en Archivo y luego abrir Archivo
4. En la ventana del archivo haz clic derecho en "Run Code" o "Ejecutar Código"
5. Se abre la terminal o consola y escribe py laberinto_datos.py
6. Se ejecuta el programa y hacer las pruebas según la guía de aprendizaje.
